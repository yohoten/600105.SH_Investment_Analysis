# 数据说明（Data README）

> 分析对象：江苏永鼎股份有限公司（**600105.SH**，以下简称"永鼎股份"或"公司"）
> 数据区间：财务数据 **2015—2025 年报 + 2026 年第三季度报告**；行情数据 **2016-01-04 — 2026-10-27**
> 抓取时间：**2026-10-27 23:21 — 23:24**（单机一次性抓取，见 `raw/_fetch_log.csv`）
> 运行环境：Windows 11 / Python 3.12 / pandas 2.2 / numpy 1.26 / matplotlib 3.9 / PyMuPDF 1.28

本目录是《证券投资学》课程投资分析报告的**全部数据底稿**。为满足"分析主体用近五年（2021—2026）、
底稿储备十年（2016—2026）"的要求，抓取年限统一向前延伸到 **2016 年**（部分接口自带 2014 年起数据），
使 2021 年以来的每一个同比、分位、CAGR 都能在 10 年样本上得到参照。

**抓取要点**

- 腾讯 K 线单次最多返回 **640 条**，故按"年"循环请求再合并去重，否则 10 年数据会被静默截断。
- 前复权与不复权走**两个不同接口路径**（`fqkline/get` 返回 `qfqday`；`kline/kline` 返回 `day`），
  用同一路径加参数切换会返回空表。
- 巨潮公告接口必须同时给出 `searchkey="年度报告"` 与 `seDate` 区间，否则会混入业绩预告、摘要等文件。
- 年报文件名格式：`永鼎股份_{年度}年年度报告_披露{披露日}.pdf`；同一年度多次披露（更正/更新）时取最早一份。

## 三、派生表口径

### 1. `ratios_annual.csv`（41 列）

| 类别 | 指标 | 计算口径 |
|------|------|----------|
| 规模 | 营业收入、归母净利润、扣非归母净利润、经营/投资/筹资现金流净额 | 合并报表，单位亿元 |
| 盈利 | 毛利率、归母净利率、期间费用率、销售/管理/研发/财务费用率 | 毛利率 =(营收−营业成本)/营收；费用率分母均为营业收入 |
| 偿债 | 流动比率、速动比率、现金比率、资产负债率、产权比率、权益乘数、利息保障倍数 | 速动资产 = 流动资产 − 存货；利息保障倍数 =(利润总额+利息费用)/利息费用 |
| 营运 | 应收/存货/固定资产/总资产/流动资产周转率及周转天数 | 分母用**期初期末平均余额**；周转天数 = 365/周转率 |
| 回报 | ROA、ROE、EPS、BPS | ROE = 归母净利润/平均归母净资产；ROA = 净利润/平均总资产 |
| 质量 | 扣非占比、净现比、收入现金比、每股经营现金流 | 扣非占比 = 扣非归母/归母；净现比 = 经营现金流净额/归母净利润 |
| 成长 | 营收/归母净利/总资产/净资产增长率 | 同比口径 |
| 校验 | 杜邦校验ROE% | 归母净利率 × 总资产周转率 × 权益乘数，与直接计算 ROE 对照（误差 < 0.1pct 视为通过） |

### 2. `quarterly_single.csv`——累计值转单季

一季报/中报/三季报/年报披露的是**年初至报告期末累计数**。分析单季经营节奏必须差分：

- 一季报 = 累计值本身；中报 = 中报累计 − 一季报累计；三季报 = 三季报累计 − 中报累计；年报 = 年报累计 − 三季报累计。
- 仅对**流量科目**（利润表、现金流量表全部项目）差分，存量科目（资产负债表中货币资金、存货等）直接取期末值。
- 报告期识别用 `endswith("一季报"/"中报"/"三季报"/"年报")`；**不可用 `str[-3:]`**——"一季报"是 4 个字符，
  截取末 3 位会得到"季报"而匹配失败，这是本项目前期出现过的一次严重口径错误（曾使 2025 三季报单季营收虚增至 27.5 亿元）。

### 3. `valuation_daily.csv`——TTM 与"防前视偏差"

- TTM 归母净利润 = 最近 4 个**单季**归母净利润之和；TTM 营收同理。
- 关键点：某一期财报的 TTM 值只在**实际公告日（`NOTICE_DATE`）之后**才允许用于估值，不能按报告期直接对齐。
  实现上用 `pd.merge_asof(direction="backward")` 以公告日为阶梯键向右填充到每个交易日，确保任一日期的
  PE/PB 只使用当日"已公开"的信息。若按报告期末硬对齐，2026 年 8—10 月的 PE 会提前用到 10 月底才披露的三季报，
  造成明显的**前视偏差（look-ahead bias）**。
- PE_TTM = 总市值 / TTM 归母净利润；PB = 总市值 / 归母净资产；PS_TTM = 总市值 / TTM 营业收入。
  总市值 = 不复权收盘价 × 报告期股本（股本变动按公告日生效）。

### 4. `segment_income.csv`——分产品收入与毛利率

- 取年报/半年报"主营业务分行业、分产品情况"表，统一业务板块命名（光通信及光电缆、汽车线束、
  电力工程、超导及铜导体、其他），保留 178 条记录以便重构任意年度的收入结构。
- 2021 年起公司口径调整较大，**分产品毛利率只做 2021H1 之后的连续比较**；2014—2020 年数据仅用于收入结构回顾。

## 五、已知局限与处理

1. **行情接口更换**：东方财富 `push2his.eastmoney.com`、`push2.eastmoney.com` 在本机网络下连接被拒
   （curl 返回码 56），行情改用腾讯财经；估值结论已与腾讯实时快照、东方财富 F10 指标交叉验证。
2. **同业面板不含本公司**：东方财富同业接口只返回 6 家可比公司，**不含 600105**。若直接绘图会出现
   "同业对比图里没有主角"的问题，故在 `scripts/analysis_lib.py` 的 `_peer_plus_yd()` 中按同一口径
   把公司自身 2016—2025 年度指标补入面板（字段：营收、毛利率、净利率、加权 ROE、资产负债率、
   总资产周转率、流动比率）。
3. **不复权日线首次抓取失败**（路径参数错误），已由 `scripts/01b_fix.py` 补抓，日志中第 2 行为失败记录。
4. **中际旭创 2017 年营收增速 1690%**：系重大资产重组并表所致，非内生增长，同业增速图中已做截断处理并注明。
5. **LPR 仅有近一年明细**：中国货币网历史接口限制，宏观利率环境改用 1 年期 LPR 现值 + 存款准备金率序列描述。
6. **2025 年净利润的构成需特别注意**：归母净利润 2.34 亿元中含对联营企业东昌投资的权益法投资收益 2.74 亿元
   （源自其房地产业务处置项目子公司），**扣非后仅 2.27 亿元，且主业经营利润为负**。任何以 2025 年
   "净利大幅增长"为前提的估值判断都会失真，报告中已单独拆解（见 图3-8）。
